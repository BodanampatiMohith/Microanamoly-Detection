## 🔍 Quick Reference

### Colors Used
- **Background**: #0B0F1A (Deep Navy)
- **Accent**: #00E5FF (Cyan)
- **Normal**: #2ECC71 (Green)
- **Warning**: #FFB300 (Amber)
- **Fault**: #FF3B30 (Red)

*Full color scheme in* → **DASHBOARD_USER_GUIDE.md**

### Displayed Metrics
1. Dominant Frequency (Hz)
2. RMS Acceleration (g)
3. Variance (σ²)
4. Peak-to-Peak (mm)
5. Spectral Energy (dB)
6. System Status

*Full metric descriptions in* → **DASHBOARD_USER_GUIDE.md**

### Control Parameters
- **Amplification**: 1-100× (adjustable slider)
- **Frequency Band**: Low 0-100 Hz, High 0-150 Hz
- **Monitoring**: Start/Stop button
- **System**: Reset button

*Full control guide in* → **DASHBOARD_USER_GUIDE.md**

### Stability Zones
- **Normal (Green)**: 75-100 stability index
- **Warning (Amber)**: 50-75 stability index
- **Fault (Red)**: 0-50 stability index

*Zone interpretation in* → **DASHBOARD_USER_GUIDE.md**
